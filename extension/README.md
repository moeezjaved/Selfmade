# Selfmade — Save Winning Ads (Chrome extension)

Save ads from **Instagram, the Facebook Ad Library, TikTok, and any page** straight into your
Selfmade boards — the Atria-style "save while you browse" workflow.

## How it works
- **Facebook Ad Library** — a full-width **＋ Save to Selfmade** button is injected into every ad
  card (Atria-style), so saving is one click, no hover needed.
- **Instagram / TikTok / anywhere** — **hover** any image or video → a **＋ Save** button appears.
- Or use the round **Selfmade button** (bottom-right) to grab the main media on the page.
- Saves land in your **boards** (default: a "🌐 Saved from Web" board; pick another in the popup).
- Media is copied to Selfmade storage (R2) so it survives Instagram/TikTok CDN expiry.

> ⚠️ Turn off ad blockers on the Facebook Ad Library — they hide/alter the ad DOM and break saving
> (Atria's extension warns about the same thing).

## Auth
One-click SSO: click the toolbar icon → **Sign in with Selfmade**. This opens `tryselfmade.ai`,
you click **Connect**, and a token flows back to the extension (via `chrome.identity`). No password
is ever entered into the extension. Under the hood it reuses the same `mcp_keys` token store as the
API, labelled "Chrome Extension" (revocable from Settings).

## Install (unpacked, for dev / review)
1. Open `chrome://extensions`
2. Toggle **Developer mode** (top-right)
3. Click **Load unpacked** and select this `extension/` folder
4. Pin the Selfmade icon, click it, **Sign in with Selfmade**
5. Go to instagram.com or facebook.com/ads/library and hover any ad → **＋ Save**

## Files
| File | Role |
|------|------|
| `manifest.json` | MV3 manifest (content script on `<all_urls>`, background worker, popup) |
| `background.js` | Token storage + all authed API calls + SSO (`launchWebAuthFlow`) |
| `content.js` | Hover-to-save button, floating button, per-host metadata extraction |
| `content.css` | Injected UI styles |
| `popup.html` / `popup.js` | Sign-in state + default-board picker |
| `icons/` | Generated by `node scripts/gen-icons.js` |

## Backend endpoints (in the Next.js app)
- `POST /api/extension/token` — session-authed; mints/returns the extension token
- `GET  /api/extension/boards` — Bearer-authed; lists boards for the picker
- `POST /api/extension/save` — Bearer-authed; persists external media to R2 + saves to a board
- `/extension/auth` — the SSO authorize page

## Publishing
Zip the folder contents (not the parent dir): `cd extension && zip -r ../selfmade-extension.zip . -x "scripts/*"`
then upload to the Chrome Web Store dashboard. The `key`/extension-ID becomes fixed on publish;
`launchWebAuthFlow` needs no code change since it uses the runtime-provided `chromiumapp.org`
redirect.
